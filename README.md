## 👋 About

I develop open-source **R software for reproducible biomedical data science**. My work focuses on **trustworthy machine learning**, **leakage-aware model evaluation**, and **transparent statistical workflows**. Through methodological studies and software tools, I aim to improve the reliability and reproducibility of computational analyses in clinical and biological datasets.

**Focus areas:** leakage-aware evaluation · reproducible workflows · bioinformatics · cheminformatics · R package development

## 🌐 Web tools and apps

- 🎓 **[BioStatQuest](https://www.biostatquest.com/)** ([source](https://github.com/selcukorkmaz/BioStatQuest)): a gamified biostatistics trainer with 50+ case-based challenges and 1,000+ questions, plus R running in the browser via WebR.
- 🧪 **[BioVar](https://github.com/selcukorkmaz/BioVar)**: online biological variation analysis for clinical laboratory data.
- 🧬 **[geneSurv](https://github.com/selcukorkmaz/geneSurv)**: interactive survival analysis for genomics research.
- 💊 **[MLViS](https://github.com/selcukorkmaz/MLViS)**: machine learning-based virtual screening for early-phase drug discovery.
